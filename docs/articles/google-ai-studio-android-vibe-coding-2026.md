# Google открыла Android-разработку в браузере: Gemini генерирует приложения без кода

На конференции **Google I/O 2026** компания представила функцию создания нативных Android-приложений в браузере через Google AI Studio. Пользователь описывает приложение словами — система возвращает готовый проект на основе **ИИ-генерации кода**. Конференция прошла во вторник.

## В Google AI Studio появился вибро-кодинг: приложение собирается по текстовому запросу

**Вибро-кодинг** (vibe coding) — подход, при котором код пишет ИИ по текстовому описанию, а человек формулирует задачу и оценивает результат. Google реализовала это прямо в браузере: **Google AI Studio теперь создаёт нативные Android-приложения без единой строки ручного кода**.

Достаточно описать приложение словами — система возвращает готовый проект без установки локальных инструментов. Опубликовать результат в Google Play напрямую не получится: потребуются дополнительные шаги.

## I/O 2026 стал площадкой для переформатирования всей экосистемы Gemini

**Google I/O 2026 представил комплексное обновление экосистемы Gemini**, включая функцию Daily Brief, переработанный интерфейс, видеомодель Gemini Omni и агента Gemini Spark. Google формулирует цель как превращение Gemini в универсальный ИИ-центр для конкуренции с ChatGPT и Claude.

Daily Brief собирает персонализированный утренний дайджест из почты, календаря и списка задач. **Gemini Spark** реализует расширенные агентные возможности внутри приложения Gemini.

Параллельно запущен тарифный план AI Ultra за $100. Лимит использования в нём в пять раз выше плана AI Pro.

## Разработчики больше не нужны для создания прототипа

Исторически мобильная разработка требовала Android Studio, Java или Kotlin и недель на настройку среды. Браузерный вибро-кодинг убирает этот порог: дизайнер или продакт-менеджер может проверить идею за минуты, не привлекая команду. Это не замена разработчику на этапе production — это инструмент для первой итерации, которая раньше занимала спринт.
