# **Anthropic выпустила Claude Opus 4.8: в 4 раза меньше ошибок в коде и параллельные агенты**

**Лид**
Anthropic представила обновление **Claude Opus 4.8** — **нейросеть для программирования**, которая демонстрирует **в 4 раза меньше ошибок в коде** по сравнению с предшественником. Также модель получила новые функции для **параллельной работы агентов** и **контроля вычислительных ресурсов**. Выпуск доступен по тем же ценам с 28 мая 2026 года через платформы Anthropic.

---

## **Что нового в Claude Opus 4.8: параллельные агенты и управление ресурсами**

Одна из ключевых новинок — **Dynamic Workflows в Claude Code**. Эта функция позволяет запускать **сотни параллельных подагентов** в рамках одной сессии. Пользователи могут разбивать сложные задачи на подзадачи и распределять их между несколькими агентами, которые работают одновременно [1].

Другая важная функция — **контроль уровня обработки в claude.ai**. Теперь пользователи могут выбирать между **быстрым, стандартным и максимальным режимами**. Это позволяет балансировать между **скоростью выполнения** и **качеством результата** в зависимости от текущих задач. Например, для прототипирования подходит быстрый режим, а для критически важных задач — максимальный [1].

**Messages API** также получил обновление: теперь **системные записи** можно передавать внутри массива сообщений без нарушения кэша. Это упрощает работу с **длинными контекстами** и позволяет более гибко управлять состоянием сессии. Все изменения в API совместимы с существующими интеграциями, что минимизирует усилия для разработчиков [1].

## **Почему обновление важно для разработчиков и стартапов**

Для инженеров, работающих с **ИИ-помощниками**, главное преимущество **Opus 4.8** — **значительное снижение количества ошибок в коде**. Это особенно актуально для команд, которые используют модели для автоматизации рутинных задач или генерации **boilerplate-кода**. Снижение частоты ошибок означает меньше времени на ревью и исправление, а значит — более высокую **продуктивность разработки** [1].

Новые функции **Dynamic Workflows** и **контроля ресурсов** открывают возможности для более сложных сценариев использования. Например, разработчики могут автоматизировать процессы, требующие **параллельного выполнения** множества подзадач — от тестирования до деплоя. Это особенно ценно для **стартапов** и команд с ограниченными ресурсами, которым нужно максимально эффективно использовать **ИИ-инструменты** [1].

Важно отметить, что все улучшения не привели к росту цен. **Claude Opus 4.8** доступен по тем же тарифам, что и предыдущая версия: **$5 за 1M входящих токенов** и **$25 за 1M исходящих** в стандартном режиме. Это делает обновление особенно привлекательным для команд, которые уже используют **Anthropic** и хотят получить больше возможностей без дополнительных затрат [1].
