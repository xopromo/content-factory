# Ошибка: галлюцинации в статье вместо верифицированных фактов

- **Что пошло не так:** content-writer написал конкретные цифры, названия организаций и события (93.9% SWE-bench, Project Glasswing, атака на водопровод), которых не было ни в одном найденном источнике. Модель заполнила пустоты «правдоподобными» фактами из тренировочных данных.

- **Почему это ошибка:** читатель-специалист проверяет цифры за 30 секунд. Один невалидный факт уничтожает доверие ко всему блогу. Для ниши ИИ-инструментов достоверность — единственное конкурентное преимущество.

- **Как писать правильно:** писать ТОЛЬКО то, что явно подтверждается переданными источниками с URL. После каждого факта — ссылка [N] на источник. Если источников не хватает — писать [INSUFFICIENT_SOURCES] и указывать чего не хватает. Никогда не дополнять «из общих знаний».
