# Ошибки в новостных статьях

## Ошибка 1: Термин без определения
- **Что пошло не так:** «вибро-кодинг» использовался без объяснения
- **Почему это ошибка:** читатель может не знать термин; первое упоминание должно давать определение
- **Как писать правильно:** «**Вибро-кодинг** (vibe coding) — подход, при котором код пишет ИИ по текстовому описанию, а человек формулирует задачу и оценивает результат»

## Ошибка 2: Заголовок в стиле соцсетей
- **Что пошло не так:** «Что вибро-кодинг даёт вам прямо сейчас» — обращение на «вы», clickbait-тон
- **Почему это ошибка:** нецроосетевой стиль не соответствует голосу автора; H2 должен быть тезисом, а не вопросом
- **Как писать правильно:** «Разработчики больше не нужны для создания прототипа» — утверждение-тезис

## Ошибка 3: Вывод = пересказ
- **Что пошло не так:** вывод дословно повторял факты из статьи теми же словами
- **Почему это ошибка:** вывод — это новая мысль, следствие или более широкий контекст, а не резюме
- **Как писать правильно:** вывод должен давать читателю что-то, чего не было явно в тексте — контекст, последствие, смена угла зрения
